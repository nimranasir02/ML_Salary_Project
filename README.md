# Salary Prediction Machine Learning Project

## Project Description

This project predicts salary based on years of experience using Machine Learning.

## Dataset

The dataset contains two main columns:

- Experience Years
- Salary

## Machine Learning Model

Linear Regression was used to train the model.

## Model Evaluation

- R² Score: 0.9831
- MAE: 4056.34
- MSE: 23745684.25

## Streamlit App

A Streamlit web application was created where the user enters their years of experience and receives a predicted salary.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib
